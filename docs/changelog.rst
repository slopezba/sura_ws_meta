Changelog
=========

This page tracks relevant changes in SURA releases and workspace compositions.

First Version
-------------

Initial public documentation and workspace composition for SURA.

This version includes:

* Overview of the SURA architecture for surface and underwater robots.
* Installation instructions for the Raspberry Pi and Docker-based runtime.
* Robot setup guides for BlueROV Heavy and BlueBoat.
* Simulation documentation.
* Package-level documentation for bringup, hardware interfaces, sensors,
  cameras, controllers, localization, navigation, IMU processing, diagnostics
  and messages.
* URDF/xacro and ``ros2_control`` documentation for robot description packages.
* Sensor, thruster and actuator integration guides.
* Development guide for extending SURA with new robots and hardware.
* Initial ``workspace.repos`` manifest for recreating the workspace composition.

The first version is focused on making the structure of SURA understandable and
on documenting the setup path for real Blue Robotics-based platforms.
