SURA Architecture
=================

SURA, **Surface and Underwater Robotic Architecture**, is a modular ROS 2
workspace for developing and running software on marine robots. It brings
together navigation, control, sensors, teleoperation, diagnostics and mission
execution for USVs, ROVs, AUVs, UVMs and UVDMs.

About This Documentation
========================

This documentation describes how the SURA workspace is organized, how to install
and run it, and how its main ROS 2 packages fit together. It is intended as a
technical reference for developers and operators working with SURA-based marine
robots.
